Setting up for the first time

The first time the program starts, a clipboard icon appears in the notification area and the Settings window opens, because the program needs to know which server key to trust before it can send anything.

  1. On the Server tab, check the host (normally pastes.glitchwrks.com) and port (normally 443).
  2. Enter the server's key pin in Key pins. Get pin from server... can fetch it for you, but you must check it against a trusted source.
  3. Look through the other tabs if you like; the defaults suit most people. See Settings.
  4. Press OK.

The program then connects to the server in the background. Status shows Ready when it has, and you can send your first paste. You are asked for your username and password the first time you send.
