Settings

Settings... in the tray menu opens the Settings window. Each tab has its own page:

  • Server: where pastes go, and which key to trust
  • Connection: encryption choices, timeout and start-up connection
  • Pastes: what happens before and after sending
  • Account: the remembered username
  • Appearance: the program's look

The Help button opens the page for the tab you are on. Every value is checked when you press OK. Changes take effect on the next paste; no restart is needed.

Where settings are kept

Settings are saved in PASTE98.PRF in the program's folder, not in the Windows registry. The previous version is kept as PASTE98.BAK in case saving is interrupted.

PASTE98.PRF is plain text, but change settings in the Settings window: it checks every value, while a mistake made by hand is ignored (with a note in PASTE98.LOG) and the default used instead.

Copying settings to another machine

Export... saves the settings to an XML file in Java's standard preferences format. Import... reads one back into the Settings window for you to review before pressing OK. Exported files contain the server, pins and username, never the password.
