Appearance settings

SettingDefaultWhat it does
Look and feelJava Metal, classic (Steel)The look of the program's windows. Changes apply as soon as you press OK.
  • Java Metal, classic (Steel) is the Swing look of Java 1.2 to 1.4. The program looks like a Java program on purpose.
  • Java Metal, Ocean (needs Java 5) is the look Java 5 introduced. On older Java the program uses Steel instead.
  • Windows uses the system's controls, but not quite its text. Windows 95 and 98 draw dialogs in MS Sans Serif, a bitmap font, and Java can only draw outline fonts. The program uses Microsoft Sans Serif (an outline version of MS Sans Serif, which comes with Windows 2000 and later and some applications) or Tahoma if either is installed, and otherwise Java's default, Arial.

Status shows which look and font are in use. The tray menu is drawn by Windows whatever you choose.
