About gw_paste98

gw_paste98 @VERSION@ is a notification area ("system tray") program for Windows 95 and 98 that sends text to the Glitch Works pastes service and puts the new paste's address on the clipboard.

It needs Java 1.3 or later. It is tested with Java 1.3.1, the last for Windows 95, and Java 1.5.0_22, the last for Windows 98.

In this help

  • Installing, upgrading and removing
  • Setting up for the first time, including the server's key pin
  • Sending pastes, the Status window and the command line
  • Settings, one page per tab
  • If something goes wrong and the program's files

Opening this help

Choose Help... from the tray icon's menu, the gw_paste98 Help item in the Start Menu, or the Help button in the Settings window, which opens the page for the tab you are on.
