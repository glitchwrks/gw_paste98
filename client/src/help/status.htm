Status

Status... in the tray menu shows:

  • The connection: Ready once the start-up connection has succeeded, Connecting while it runs, Offline if the server could not be reached (not permanent: sending a paste tries again), or KEY MISMATCH if the server presented a key that matches none of your pins.
  • The encryption in use: the TLS version and cipher agreed with the server, for example TLS 1.2 with ECDHE-RSA-AES256-GCM-SHA384.
  • The last paste's address.
  • Where things are: the settings file, the appearance and font in use, whether the tray icon is working, and the program folder.

Pointing at the tray icon shows a short version of the same status.
