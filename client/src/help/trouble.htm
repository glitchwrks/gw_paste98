If something goes wrong

Most problems are explained in PASTE98.LOG in the program folder, which is written afresh each time the program starts.

No tray icon, a small window instead

The program could not use GWTRAY.DLL. The window does the same things. The reason is at the bottom of the window and in PASTE98.LOG.

"Server key mismatch"

The server presented a different key from your pins, and nothing was sent. Either the server's key changed, in which case get and check the new pin (see The key pin), or something is intercepting the connection. Find out which before adding a new pin.

"Login failed"

Wrong username or password. You are asked again.

"Offline" in Status

The server could not be reached at start-up. Check the network and the host and port in Server settings. Sending a paste tries again.

The first paste is slow

The first encrypted connection takes a couple of seconds on a Pentium-class machine. Leave Connect at start-up to warm up the encryption code on (see Connection settings) so it happens in the background.

Setup says the program is running

Exit it from the tray icon's menu, then press Retry.

Setup says Java was not found

Install the Java 5 runtime (1.5.0_22) and run setup again.

Help does not open

This help needs HTML Help, which comes with Windows 98 and Internet Explorer 4 or later. You can also open GWPASTE.CHM in the program folder directly.
