Installing

Install Java first: any Java runtime from 1.3 on. The newest each system can run is Java 1.3.1 on Windows 95 and Java 1.5.0_22 (Java 5) on Windows 98. Java 5 is a little faster and offers the Ocean look; everything else works the same on both.

With the installer

  1. Run pastejar-version-setup.exe. It finds Java (1.3 or later) through the registry and refuses to continue without it. With several installed, it uses the current version.
  2. Choose the parts to install:
    • Start Menu shortcuts: a Paste Jar folder with the program, this help and the uninstaller.
    • Start with Windows: starts the program when Windows starts. Off unless an earlier install had it on.
    • Start Paste Jar when setup closes: starts the program when you press Close at the end of setup.
  3. Choose the folder; the default is C:\Program Files\Paste Jar.
  4. Setup ends with a log of what it did; press Close. The program starts if you chose to, or start it from the Start Menu. Then follow Setting up for the first time.

The shortcuts point at the Java that setup found, so run setup again if you move or replace Java.

From the zip

  1. Copy the pastejar folder anywhere, for example C:\PASTEJAR.
  2. Run PASTEJAR.BAT.

To start it with Windows, make a shortcut in C:\WINDOWS\Start Menu\Programs\StartUp with the target

"C:\Program Files\Java\jre1.5.0_22\bin\javaw.exe" -Xmx32m -jar C:\PASTEJAR\GWPASTE.JAR

adjusting both paths to where Java and the program actually are (Java 1.3.1 installs to C:\Program Files\JavaSoft\JRE\1.3.1).

Upgrading

Exit the program (right-click the tray icon and choose Exit), then run the new setup. Setup will not continue while the program is running, because Windows cannot replace files in use. Your settings and key pins in PASTE98.PRF are kept, and so is your Start with Windows choice.

From the zip: exit the program and copy the new files over the old ones. To move from the zip to the installer, copy PASTE98.PRF into the installed folder before starting the installed copy.

Upgrading from gw_paste98 (Paste Jar's name up to version 0.8.1): run the new setup as above. It installs to C:\Program Files\Paste Jar, moves your settings, key pins and Start with Windows choice over from the old folder, and removes the old program, its Start Menu items and its entry in Add/Remove Programs. From the zip: copy PASTE98.PRF from the old folder into the new one.

Upgrading from version 0.1.x: on first start, the program copies your settings from PASTE98.CFG and PASTE98.USR, renames PASTE98.CFG to PASTE98.OLD and deletes PASTE98.USR.

Removing

Use Add/Remove Programs in Control Panel, or Uninstall Paste Jar in the Start Menu. It asks whether to keep your settings and key pins; keep them if you might install the program again.
