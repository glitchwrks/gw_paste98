Sending pastes

Right-click the tray icon for the menu; double-click it to open a new paste.

Menu itemWhat it does
New paste...Opens an editor. Type or paste text and press Send (or Ctrl+Enter).
Paste clipboardSends the text on the clipboard. By default it shows the start of the text and asks first.
Status...Shows the connection and the last paste. See Status.
Settings...Changes the settings. See Settings.
Help...Opens this help.
About...Shows the version, Java and encryption library in use.
ExitRemoves the icon and quits, forgetting your password.

If the program cannot use the tray (see If something goes wrong), a small window with the same buttons appears instead.

Logging in

The first time you send, the program asks for your pastes username and password. The password is kept in memory only, until you exit. The username can be remembered; see Account settings. If the server rejects the login, you are asked again.

The new paste's address

When a paste is created, its address (for example https://pastes.glitchwrks.com/k3x9q2ab) is copied to the clipboard and shown in a window. Either can be turned off in Pastes settings; the last address is always in Status.

Limits

  • At most 65,535 characters per paste, the server's limit.
  • The server stores text as Latin-1 (Western European). Characters outside it, such as the euro sign, are stored as ?. The program warns before sending such text.
