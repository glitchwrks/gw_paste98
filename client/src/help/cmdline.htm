The command line

SENDFILE filename

sends a text file as a paste and prints its address, using the settings saved by the tray program. The password comes from the PASTE98_PASSWORD environment variable, and the username from the remembered username (or add --user NAME). For example, at an MS-DOS Prompt:

SET PASTE98_PASSWORD=yourpassword
SENDFILE C:\AUTOEXEC.BAT

The installer writes SENDFILE.BAT with the full paths of Java and the program, so it works from any folder; add the program folder to your PATH to run it by name. The zip's SENDFILE.BAT must be run from the program folder, with Java on the PATH.

Other options for GWPASTE.JAR: --version prints the version, and --no-tray starts the program with its window instead of a tray icon.
