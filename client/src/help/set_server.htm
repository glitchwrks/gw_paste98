Server settings

SettingDefaultWhat it does
Hostpastes.glitchwrks.comThe pastes server's name.
Port443The server's HTTPS port.
Key pinsnone; requiredOne per line: the base64 SHA-256 hash of the server's public key. The program only talks to a server holding one of these keys. See The key pin.

Get pin from server... reads the pin from the host and port above. The pin it shows is not verified; check it against a trusted source before adding it. See The key pin.

Changing the host or port logs you out, so your password is never sent to a different server.
