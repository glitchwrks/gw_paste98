Connection settings

SettingDefaultWhat it does
CipherAutomatic (ChaCha20 preferred)The encryption offered to the server. ChaCha20-Poly1305 is fastest on processors without AES instructions, which includes every Windows 98-era processor. The server makes the final choice; only choices offer just one.
Key exchangeAutomatic (X25519 preferred)How the connection's keys are agreed. X25519 is about three times faster than P-256 on a Pentium III.
Timeout30 secondsHow long to wait for the server before giving up, from 5 to 300 seconds.
Connect at start-up to warm up the encryption codeonConnects once in the background at start-up, so the first paste takes about half a second instead of two or three. Turn it off if the machine is often offline.

Status shows the cipher and key exchange actually in use.
